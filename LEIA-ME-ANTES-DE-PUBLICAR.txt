COMO PUBLICAR NA VERCEL
1. Use ESTE ZIP como substituição completa do projeto atual.
2. Não misture com a pasta antiga. O objetivo é remover as páginas dos outros estados.
3. Faça um novo deploy com todos os arquivos deste pacote.
4. Depois teste:
   https://departamento-de-transito.vercel.app/

   https://departamento-de-transito.vercel.app/robots.txt

GOOGLE SEARCH CONSOLE
- Em Sitemaps, envie somente: sitemap.xml
- Não envie arquivos .html no campo de sitemap.
- O sitemap contém apenas páginas focadas em São Paulo.

IMPORTANTE SOBRE AS PÁGINAS ANTIGAS
- As páginas dos outros 26 estados NÃO estão neste projeto e NÃO estão no sitemap.
- Ao substituir o projeto inteiro, elas deixarão de existir e retornarão 404, permitindo que o Google as remova gradualmente do índice.
- Não redirecione páginas de outros estados para SP apenas para tentar manter tráfego; isso seria uma correspondência ruim para a intenção do usuário.
- O vercel.json redireciona apenas páginas genéricas antigas para páginas equivalentes de São Paulo.
